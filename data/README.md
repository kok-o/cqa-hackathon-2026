# Локальные данные

`raw/` содержит ответы API, `runtime/` — SQLite, `evaluations/` — результаты прогонов. Эти папки исключены из Git.

Получение DEV выполняется через `scripts/fetch_dataset.py`. Подписанный URL берётся из `.env`. Контрольный group_id задаётся объявлением организаторов.

Синтетические примеры для разработки хранятся в `fixtures/`.
