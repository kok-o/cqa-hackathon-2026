# Приёмка и защита

## Сквозные сценарии

| Проверка | Ожидаемое поведение |
|---|---|
| Импорт DEV | Число записей сверяется с ответом, ID уникальны, RU/KZ/EN и оба канала распознаются |
| Повторный импорт | Сохраняется согласованная версия данных без дублирования диалогов |
| Редактор | Изменение названия, инструкции, веса, типа, шкалы и N/A сохраняет новую версию |
| Новая версия | Старый запуск остаётся привязанным к прежней конфигурации |
| Оценка | Все критерии версии получают ответ или видимый статус неполноты |
| Доказательство | ID существует, цитата соответствует оригиналу, переход открывает нужную реплику |
| Пропущенное действие | Показан проверенный диапазон разговора и причина вывода |
| Роли | Реплики bot/system/client служат контекстом, работа оценивается у operator |
| N/A | Причина видна, веса пересчитаны по официальному правилу |
| Грубая ошибка | Флаг виден и применено предусмотренное правило |
| Звук | Запись открывается, включая HTML-плеер организаторов; ошибка загрузки видна и доступен повтор. При отсутствии таймкодов не заявлять переход к точному фрагменту |
| Апелляция | Комментарий, критерий, исходная оценка и доказательство доступны проверяющему |
| Решение | Причина обязательна, результат пересчитан, история сохранена |
| Два решения | Устаревшая ревизия получает конфликт, повторный запрос обработан идемпотентно |
| Перезапуск | Диалоги, конфигурации, оценки и апелляции доступны после перезапуска |
| Сбой модели | Видимый статус, ограниченный повтор, отсутствие фиктивного успешного результата |
| Новый критерий | Добавленный через UI критерий применяется к новому запуску |
| Контроль | Данные T+23 импортируются тем же способом и проходят тот же пайплайн |

## Проверка качества AI

На вручную разобранном срезе сохраняются ожидаемые ответы и доказательства. Отчёт показывает совпадение по критериям, ошибки по языкам и каналам, выдуманные цитаты, корректность N/A, пропуски грубых нарушений и время обработки. Метрики сопровождаются размером выборки. Стоимость включает все вызовы и повторы одной полной оценки.

Воспроизводимая [репетиция на 10 новых синтетических чатах](../fixtures/readiness/README.md)
разделяет платную оценку, авторские проверки и бесплатные API/UI-тесты.
Синтетические ожидания не заменяют GT организаторов. Итоговая матрица готовности
и ограничения — в [READINESS_AUDIT.md](READINESS_AUDIT.md).

## Сдача

Дедлайн — **8 ноября 2026, 12:00 по Астане (UTC+05:00)**, подтверждён [расписанием](https://datachallenge.datasci.website/ru/schedule). Час на контрольные десять чатов включает оценку, выгрузку JSON, commit и push. Ориентир T+23 даёт 11:00, но отдельное сообщение о фактической выдаче ещё нужно проверить в Announcements. К стоп-коду сохранить последний коммит и его SHA. После стоп-кода обработка данных и изменение чек-листа через готовый интерфейс выполняются на зафиксированной версии.

В репозитории должны быть `results/dev/results.json` и `results/prod/results.json`; второе создаётся только после реальной обработки контроля. Форма бинго и feedback-форма не являются формой сдачи проекта. Развёрнутое приложение не заменяет обязательные файлы и push. Короткая [памятка команды](HACKATHON_BRIEF.md) содержит актуальные источники и оставшиеся вопросы.

Перед отправкой ссылки владелец проверяет содержимое и меняет текущую приватность на требуемый организаторами открытый доступ. В репозитории доступны код, инструкции, синтетические примеры и используемые конфигурации. Секреты и исходные записи поставляются через локальные настройки и официальный источник.

## Репетиция на пять минут

| Время | Что показать | Кто говорит |
|---|---|---|
| 0:00–1:00 | Интерфейс, выбранный диалог, версия чек-листа | Олжас |
| 1:00–3:00 | Оценка, доказательство, переход к реплике, N/A и итог | Нурхан |
| 3:00–4:00 | Апелляция, решение проверяющего и новый итог | Нариман |
| 4:00–5:00 | Изменение критерия и применение новой версии | Олжас |

Порядок соответствует заданию. Во время репетиции измерить фактическое время, проверить сеть и звук, подготовить локальные графики и сохранённый успешно завершённый запуск. Для заранее посчитанного результата явно указать время и версию.
