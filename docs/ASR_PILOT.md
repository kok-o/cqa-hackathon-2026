# Пилот распознавания записей

Проверка отделена от рабочего CQA: новые расшифровки сохраняются локально,
исходные диалоги и результаты DEV не перезаписываются. Контрольные десять
диалогов организаторов — чаты; ASR проверяется как дополнительная возможность.

## Полученный результат, 7 ноября 2026

GPT-Transcribe успешно обработал **5/5 записей** без повторов и неизвестных
расходов. Расчёт по длительности — **$0.15714**. Суммарное время пяти API-запросов
34.06 с; загрузка, локальная проверка и запросы вместе — около 88.33 с.

| Звонок | Длительность | API, с | Точные совпадения ориентиров | Различие токенов с исходным текстом |
|---|---:|---:|---:|---:|
| p4-ru-001 | 5.20 мин | 6.54 | 5/5 | 18.99% |
| p4-ru-002 | 10.34 мин | 8.54 | 4/5 | 37.15% |
| p4-ru-003 | 6.55 мин | 6.02 | 5/5 | 36.02% |
| p4-ru-004 | 7.07 мин | 6.86 | 5/5 | 38.65% |
| p4-ru-005 | 5.76 мин | 6.10 | 5/5 | 26.48% |

Итого 24/25 **точных лексических совпадений**, не «96% точности ASR».
При просмотре текста единственный несовпавший ориентир обнаружен в другой
грамматической форме. Это само по себе не доказывает смысловую ошибку модели;
замороженная метрика остаётся 24/25. Последний столбец измеряет различия между
двумя расшифровками, а не ошибки относительно прослушанной человеческой разметки.
Преимущество над исходной расшифровкой или FreedomSpeech этим не установлено.

Новые тексты не назначают ролей и не доказывают точность временных меток.
Рабочая оценка продолжает использовать исходные диалоги; автоматической подмены
нет. [Подробный отчёт](validation/asr-pilot/report.json) содержит значения и
статусы запросов. FreedomSpeech подготовлен, но не запускался: нет ключа и тарифа.

## Сравнение

Пять доступных DEV-звонков: 34.9203 минуты, все с языковой меткой RU.
Перед запросами зафиксированы длительности, источники и 25 текстовых ориентиров
из предоставленных расшифровок. Ориентиры и эталонный текст не отправляются ASR.

GPT-Transcribe получает файл, языковую подсказку и общий контекст
«Customer support call at Freedom Broker.». По [официальному тарифу](https://developers.openai.com/api/docs/models/gpt-transcribe) $0.0045/мин
оценка пяти записей — $0.15714. Лимит пилота $0.25; резерв $0.171 учитывает
округление вверх. Это расчёт по длительности, не проверенный счёт.

Метрики: сколько из 25 заранее выбранных терминов сохранилось, различие токенов
с исходной расшифровкой, время запроса и стоимость. **Различие с исходным текстом
не равно WER по человеческой разметке**: ошибаться может любая расшифровка.
Качество на казахской и английской речи этим набором не проверяется.

## Повторение GPT-Transcribe

Нужны локальные DEV-записи, `ffprobe`, OpenAI-ключ в `.env` и приватный файл
ориентиров. Для нового прогона выбирается новый каталог. Режим по умолчанию
только фиксирует план, без загрузки аудио и без вызовов провайдера.

```powershell
.venv/Scripts/python.exe -X utf8 scripts/transcription_pilot.py --dry-run --anchors data/evaluations/transcribe-20261107/anchors.json --out data/evaluations/transcribe-new
.venv/Scripts/python.exe -X utf8 scripts/transcription_pilot.py --run --anchors data/evaluations/transcribe-20261107/anchors.json --out data/evaluations/transcribe-new --budget-usd 0.25
```

Резерв записывается до отправки. Потерянный ответ не повторяется автоматически;
ошибки доступа или параметров останавливают оставшиеся файлы даже после resume.
Загрузка ограничена размером, временем и разрешёнными доменами на каждом
перенаправлении. Перед отправкой `ffprobe` сверяет длительность с замороженным
планом. Тексты, аудио и служебные ответы хранятся в игнорируемом `data/evaluations/`.

## FreedomSpeech

Подготовлен отдельный [runner](../scripts/freedomspeech_pilot.py) по
[официальной документации](https://freedomspeech.kz/docs/) и
[SDK](https://github.com/freedomspeechkz/freedomspeech-python).
Ключа пока нет; живые запросы не выполнялись, публичный тариф не установлен.
Тестирование механики на подставных HTTP-ответах не является проверкой качества
или доступности распознавания в реальном аккаунте.

Используются `X-API-Key`, `prettify=false` и `response_format=diarized_json`.
Пунктуационное/числовое редактирование отключено для сравнения исходного
распознавания. Сегменты и метки говорящих сохраняются, но **A/B не назначаются
ролям клиент/оператор автоматически**. Диаризация и правильность временных меток
требуют отдельной проверки по записи.

Для запуска понадобятся `FREEDOMSPEECH_API_KEY` в локальном `.env` и подтверждённые
тариф, остаток квоты и шаг тарификации. Они задаются приватным JSON:
`rate_per_minute_usd`, `quota_minutes`, `billing_increment_seconds`,
`source`, `verified_at` (YYYY-MM-DD), `user_verified=true`.
Нулевая ставка допустима только для действительно бесплатной квоты.
План с неизвестным тарифом нельзя молча использовать для платного запуска —
сначала фиксируется новый каталог с указанным тарифом.

```powershell
.venv/Scripts/python.exe -X utf8 scripts/freedomspeech_pilot.py --dry-run
# После появления ключа и фактического тарифа, пример структуры команды:
.venv/Scripts/python.exe -X utf8 scripts/freedomspeech_pilot.py --dry-run --tariff data/evaluations/freedomspeech-tariff.json --out data/evaluations/freedomspeech-new --budget-usd 0.25
.venv/Scripts/python.exe -X utf8 scripts/freedomspeech_pilot.py --run --tariff data/evaluations/freedomspeech-tariff.json --out data/evaluations/freedomspeech-new --budget-usd 0.25 --reuse-from data/evaluations/transcribe-20261107-v2
```

Сумма в примере — пользовательский потолок, а не цена FreedomSpeech.
Повторное использование аудио допускается только после проверки исходного
диалога, SHA-256 файла и длительности. Повторной загрузки того же файла не нужно.
Квота расходуется в журнале и для запросов с неизвестным результатом.

Обычный текст ASR сам по себе не проверяет дикцию, интонацию или корректность
разделения ролей. Поэтому наличие успешной расшифровки не меняет автоматически
`audio_processed` в действующем оценщике и не закрывает `requires_audio`.
