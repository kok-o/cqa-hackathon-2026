# Проверка объединения PR #4, #6 и #7

7 ноября 2026. Проверен код `7a886803f3c53182a8322eb106e4754377bbbde4`:
интерфейс Олжаса, атомарный экспорт Наримана и восстановление очереди из #4.
Последующие изменения в этом отчёте и артефактах не меняют исполняемый код.

## Исправления

- После принятого сервером запроса и потери ответа UI сохраняет ключ идемпотентности и ID задачи. Продолжение после перезагрузки использует ту же задачу. Пока очередь требует восстановления, обычный повтор и новый пакет заблокированы.
- После переимпорта выбирается оценка текущего текста. Поздно завершившаяся оценка старого источника остаётся в истории и не подменяет текущий диалог.
- Черновики апелляций и решений хранятся на уровне оценки: смена критерия, сворачивание, мобильные вкладки и Escape их сохраняют. После конфликта ревизий 409 остаются причина, ответ и доказательство.
- Экспорт читает источники и историю в одной SQLite-транзакции. Конкурентный импорт или завершение оценки не смешивает разные состояния базы внутри файла сдачи.
- Браузерные проверки обновлены для Radix Select и нового интерфейса. Исходные проверки восстановления и целостности результатов сохранены.

Все четыре браузерных прогона выполнены повторно после включения #6; JavaScript-ошибок нет.
Для каждого прогона использована временная база с механическим оценщиком; платных вызовов **0**.
Эти сценарии проверяют работу системы и частично пересекаются. Они не измеряют точность относительно Ground Truth организаторов.
Прежние модельные прогоны и их ограничения остаются в [FAULT_REHEARSAL.md](FAULT_REHEARSAL.md).

Снимки desktop/mobile просмотрены. Статический Impeccable detector отметил единственную зелёную полосу выбранного диалога; она оставлена как индикатор выбора в существующем дизайне. Это regex-проверка, а не замена проверке в браузере.

## Повторный запуск

В одном терминале (Python-окружение с зависимостями backend):

```sh
python scripts/ui_test_server.py --port 8040
```

В другом терминале (Python с Playwright, httpx и установленным Chrome):

```sh
python scripts/browser_faults.py --url http://127.0.0.1:8040
python scripts/browser_smoke.py --url http://127.0.0.1:8040
python scripts/browser_readiness.py --url http://127.0.0.1:8040
python scripts/frontend_review_smoke.py --url http://127.0.0.1:8040
python scripts/fault_http_rehearsal.py --out scratch/fault-http.json
```

Отчёты, хеши исходников и синтетические снимки сохранены отдельно от прежних модельных свидетельств: [validation/pr-integration](validation/pr-integration/summary.json).
