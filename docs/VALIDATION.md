## Выполненные проверки

- 44 автоматических теста API, контрактов, расчёта, адаптера и метрик проходят.
- `pip check`: конфликтов зависимостей нет.
- `npm run build`: TypeScript и production-сборка проходят.
- Установка Python-зависимостей выполнена в отдельной `.venv`.
- Единый запуск через `scripts/start.ps1` проверен; после перезапуска сохранились все 65 диалогов DEV.
- В рабочей базе нет подставных оценок: 65 диалогов, 0 оценок; конфигурация модели отсутствует.
- Desktop 1440×1000 и mobile 390×844 проверены в Chrome. Горизонтального переполнения и ошибок JavaScript нет. Прокрутка длинного списка и транскрипта работает, нижние действия доступны.
- Сквозной браузерный сценарий выполнен на отдельной базе с явно внедрённым тестовым оценщиком: новый JSON → задача оценки → доказательство → апелляция → решение → пересчёт → новый критерий и версия → повторная оценка → ранее неизвестный JSON → экспорт.

- Метрики используют исходные ответы до апелляций. Ручные исправления не увеличивают заявленную точность AI; несовпадающие снимки диалогов отклоняются.

## Повторить автоматические проверки

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s backend/tests -v
.\.venv\Scripts\python.exe -m pip check
npm --prefix frontend run build
```

GitHub workflow `checks.yml` запускает серверные тесты и сборку интерфейса после push/PR. Удалённый CI в этой работе не запускался; исходники изменены локально.

Для браузерной проверки нужен Python с пакетом `playwright` и установленный Google Chrome. Запускайте отдельную тестовую базу, а не рабочий сервер:

```powershell
$env:CQA_BROWSER_TEST = '1'
$env:CQA_BROWSER_TEST_DB = 'scratch/browser-test.sqlite3'
.\.venv\Scripts\python.exe -m uvicorn backend.tests.browser_fixture:create_browser_app --factory --host 127.0.0.1 --port 8001
```

Во втором терминале с Python, где установлен Playwright:

```powershell
py -3.13 scripts/browser_smoke.py --url http://127.0.0.1:8001
```

Скрипт отказывается изменять сервер, если `/api/config` не содержит `mode=test`. Тестовый оценщик не включён в обычный запуск. Результат и снимки сохраняются в игнорируемую папку `scratch`.
