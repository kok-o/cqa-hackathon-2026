# Материалы задания

`CQA_Student_Guide.pdf` — копия предоставленного пользователем гайда из четырёх страниц. Из аннотаций удалена подписанная ссылка API. Визуальный текст задания сохранён.

Исходный PDF позволяет получить DEV. Скопируйте адрес кнопки на странице 3 в локальную переменную `CQA_DEV_URL`.

Официальный отдельный чек-лист с восемью критериями ожидается. После получения два участника сверяют формулировки, веса, шкалы, N/A, секции, грубые ошибки и округление. Учебная конфигурация в `fixtures/` предназначена для проверки форматов.
