# Свидетельства прогонов 7 ноября 2026

Методика, результаты и ограничения: [FAULT_REHEARSAL.md](../FAULT_REHEARSAL.md).

Повторные проверки после объединения интерфейса и атомарного экспорта: [PR_INTEGRATION_CHECK.md](../PR_INTEGRATION_CHECK.md), артефакты в [pr-integration/summary.json](pr-integration/summary.json). Прежние свидетельства ниже сохранены без перезаписи.

| Файлы | Содержание |
|---|---|
| `verification-summary.json` | Выполненные команды, число backend-тестов, hashes проверенного кода, сохранность рабочей БД |
| `lost-response-before.json` | Воспроизведённая потеря ответа: оценка есть на сервере, UI сообщает неуспех |
| `fault-http-before-fixes.json` / `fault-http-after-fixes.json` | До/после исправления гонки снимков и потери usage; локальные HTTP и процессы |
| `browser-faults-report.json` | 15 пройденных браузерных сценариев со сбоями |
| `browser-smoke-result.json` / `browser-readiness-result.json` | Обычные операции, апелляции, правила, новые чаты, аудио и размеры экрана |
| `queue-layout-report.json` | Панель восстановления очереди на трёх ширинах |
| `final-luna-ui-check.json` | Читающая проверка рабочего приложения, сохранность DEV-выгрузки |
| `adversarial-v1.json` / `adversarial-v2.json` | Сокращённые отчёты реальных API-прогонов, включая незавершённый первый |
| `adversarial-accounting.json` | Учёт обеих попыток, неизвестной usage, резерва, неизменности модельных запросов |

В HTTP-тестах и браузерных сценариях модель **механическая**, платных обращений
нет. Числа `estimated_cost` в `fault-http-*` проверяют арифметику по искусственной
usage, они не являются расходами на провайдера. Реальные модельные расходы
относятся только к `adversarial-*`.

Модельные ожидания написаны ассистентом, проверены вторым до запуска и не
подгонялись после. Это не Ground Truth организаторов. Некоторые проверки
пересекаются; их нельзя складывать в независимые наблюдения качества.
Сокращённые отчёты не содержат полного checkpoint и не позволяют независимо
пересчитать каждое решение без локальных артефактов. Полные источники,
предсказания и freeze-планы сохранены локально в `data/evaluations/`.
