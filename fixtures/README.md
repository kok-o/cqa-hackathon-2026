# Учебные примеры

Все диалоги и оценки в этой папке написаны для проверки контракта. Они не входят в официальный DEV. В голосовом примере аудио отсутствует намеренно, чтобы интерфейс мог показать это состояние. Последняя реплика EN проверяет, что пользовательский текст остаётся данными при оценке.

Файл чек-листа содержит два учебных критерия. Официальный набор из восьми критериев переносится из отдельного PDF.
