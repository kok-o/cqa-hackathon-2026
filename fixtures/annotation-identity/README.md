# Общие условия обслуживания и идентификация

Один вымышленный сценарий в трёх языковых версиях. Клиент сообщает сведения
о своём плане, оператор объясняет публичные условия и функции техподдержки,
не открывает профиль и решает вопрос навигации. Девять авторских проверок
зафиксированы до ответов v10: C3=N/A, C4=20, C8=Нет для каждой версии.

Это проверка конкретной ошибки применимости, не независимая оценка accuracy.
Отрицательные случаи — реальное раскрытие до проверки и заблокированная попытка
защищённого действия — проверяются отдельными наборами в том же запуске.
