# Проверки ошибок разметки

24 вымышленных чата: восемь семейств на RU, KZ и EN. Переводы не являются
24 независимыми сценариями. 66 целевых ожиданий зафиксированы до просмотра
ответов v9. Это авторские проверки ассистента, не человеческий или официальный GT.

Проверяются достаточность данных до подключения оператора; отложенная
идентификация при общей консультации; реальное раскрытие до проверки; корректная
навигация с отдельным предложением частной платной услуги; нейтральная вежливость
при частичном ответе; исправленная ошибочная инструкция; отправка кода без
раскрытия номера и последующая проверка; отказ помочь при жалобе.

Модели передаются только `dataset.json` и чек-лист. `expected.json` используется
после прогона:

```powershell
.venv/Scripts/python.exe -m evaluation.regression --expected fixtures/annotation-regression/expected.json --run-dir <RUN_DIR> --group ANNOTATION_REGRESSION_20261108
```

Исторические метки других наборов сохранены. Известные неоднозначные ожидания
в `fixtures/regression/ambiguities.json` и `fixtures/hybrid-holdout/ambiguities.json`
передаются через `--ambiguities`: они выводятся отдельно и не повышают счётчик
однозначных совпадений. Файл привязан к хешу исходных ожидаемых ответов. Отсутствие
ответа или значение вне допустимого набора по-прежнему не считается прохождением.
