# Интерфейс CQA

Рабочий React + TypeScript + Vite интерфейс на русском языке. Все данные приходят из FastAPI; встроенных успешных оценок нет. Шрифты Manrope поставляются локально, внешние CDN не нужны.

## Разработка

Из каталога `frontend`:

```powershell
npm ci
npm run dev
```

API должен работать на `http://127.0.0.1:8000`. Vite проксирует `/api` и `/health`. Для единого сервера выполните `npm run build`: FastAPI раздаёт `frontend/dist`.

```powershell
npm run typecheck
npm run build
```

## Что доступно

- Импорт нового JSON, локального DEV и явно учебных диалогов.
- Поиск и фильтры по набору, языку и каналу; просмотр ролей и исходных меток времени.
- Настройка всех полей критерия, добавление критериев, сохранение новой версии и нового чек-листа.
- Оценка одного диалога и последовательная очередь выбранных диалогов с прогрессом и остановкой после текущего.
- Исходная и действующая оценки, N/A, неполный результат, цитаты и проверенные участки.
- Апелляция и отдельное решение проверяющего с пересчётом; история запусков и экспорт JSON.
- Воспроизведение аудио без выдуманных смещений реплик.

При просмотре старой оценки транскрипт берётся из её сохранённого снимка. Новая версия чек-листа и повторный импорт не подменяют доказательства старого запуска.

Если модель не настроена, анализ недоступен, а импорт и редактор продолжают работать. Настройки модели и ключи находятся только на сервере; кнопка статуса объясняет способ подключения.

## Файлы

- `src/App.tsx`: загрузка данных, навигация, очередь, транскрипт и история.
- `src/ChecklistEditor.tsx`: динамический редактор критериев и версий.
- `src/Assessment.tsx`: результат, доказательства и пересмотр.
- `src/api.ts`: HTTP-адаптер и обработка ошибок.
- `src/contracts.ts`: типы, согласованные с `docs/API_CONTRACT.md`.
- `src/styles.css`: адаптивный интерфейс, фокус и состояния.

Готовая интеграция с Dynamics 365 не включена. Сборка состоит из HTML/CSS/JS; перенос в HTML-компонент потребует настройки размещения и адреса API.
